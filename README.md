# antcrew-proxy

A lightweight reverse proxy that lets you use antcrew-platform without ever giving the platform your Anthropic API key.

**How it works:**

```
antcrew-platform  →  antcrew-proxy (yours)  →  api.anthropic.com
       ↑                    ↑
  sends UUID token     holds your real
  (never sees key)     Anthropic key
```

The platform generates a UUID token and sends it on every LLM request. Your proxy validates the token, replaces it with your real Anthropic key, and forwards the request. The platform never touches your key.

---

## Setup (5 steps)

### Step 1 — Generate a token in the platform

Go to **Settings → LLM Mode**, select your workspace, and open the **Proxy** section.

Enter the public URL where you will host this proxy (e.g. `https://proxy.yourcompany.com`) and click **Generar token**.

Copy the token shown — it is only displayed once.

### Step 2 — Run antcrew-proxy

**With Docker (recommended):**

```bash
docker run -d \
  --name antcrew-proxy \
  -p 8080:8080 \
  -e ANTHROPIC_API_KEY=sk-ant-YOUR_REAL_KEY \
  -e PROXY_TOKEN=YOUR_UUID_TOKEN \
  ghcr.io/iagop03/antcrew-proxy:latest
```

**With docker-compose** — copy `docker-compose.example.yml`, fill in your values, and run:

```bash
docker compose up -d
```

**Without Docker:**

```bash
pip install -r requirements.txt
ANTHROPIC_API_KEY=sk-ant-... PROXY_TOKEN=your-token uvicorn main:app --host 0.0.0.0 --port 8080
```

### Step 3 — Verify the proxy is healthy

```bash
curl https://proxy.yourcompany.com/health
# → {"ok": true}
```

The platform will send requests to `<proxy_url>/v1/messages`. Make sure port 8080 (or whichever port you chose) is reachable from the platform.

### Step 4 — Activate proxy mode in the platform

Back in **Settings → LLM Mode**, click **Proxy ×0.7**. The workspace will switch to proxy mode immediately.

### Step 5 — Run a pipeline

Trigger any run from the platform. The LLM call goes through your proxy; your Anthropic key never leaves your network.

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `ANTHROPIC_API_KEY` | Yes | Your real Anthropic API key (`sk-ant-…`) |
| `PROXY_TOKEN` | Yes | UUID token generated by the platform |
| `ANTHROPIC_BASE_URL` | No | Override upstream endpoint (default: `https://api.anthropic.com`) |
| `HOST` | No | Bind host (default: `0.0.0.0`) |
| `PORT` | No | Bind port (default: `8080`) |

---

## Rotating the token

If you suspect the token is compromised, go to **Settings → LLM Mode → Proxy → Rotar token**. This invalidates the old token immediately. Update `PROXY_TOKEN` in your proxy container and restart it:

```bash
docker stop antcrew-proxy
docker run -d --name antcrew-proxy -p 8080:8080 \
  -e ANTHROPIC_API_KEY=sk-ant-... \
  -e PROXY_TOKEN=NEW_TOKEN \
  ghcr.io/iagop03/antcrew-proxy:latest
```

---

## Revoking proxy mode

Click **Revocar** in the platform settings. The workspace reverts to managed mode and the token is deleted. Your proxy container can be stopped.

---

## Security

- The proxy validates every request with `hmac.compare_digest` (constant-time) — no timing attacks.
- The real `ANTHROPIC_API_KEY` only exists in your container's environment; the platform stores the UUID token encrypted with Fernet at rest.
- The proxy has no persistent state — it forwards requests and does nothing else.
- Run behind a TLS terminator (nginx, Caddy, Fly.io, Cloudflare Tunnel) in production.

## Building locally

```bash
git clone https://github.com/iagop03/antcrew-proxy.git
cd antcrew-proxy
pip install -r requirements.txt
ANTHROPIC_API_KEY=sk-ant-... PROXY_TOKEN=test-token uvicorn main:app --reload
```

```bash
# Or build the Docker image
docker build -t antcrew-proxy .
docker run -p 8080:8080 -e ANTHROPIC_API_KEY=... -e PROXY_TOKEN=... antcrew-proxy
```
